\paragraph{ResNet-50 negative result.}
The ResNet-50 source checkpoint produces 11.23\% accuracy (near random), indicating a corrupted or mismatched checkpoint. UCDPA achieves 9.92\% (below source), confirming the theoretical prediction (Section~\ref{sec:disc:failure-modes}): when the source model is near-random, UCB routing cannot distinguish correct from incorrect pseudo-labels, and the error amplification bound loses its force.

\paragraph{Scale normalization.}
Disabling scale normalization yields essentially identical accuracy ($\Delta=\scalenormDelta{}$~pp) but increases Mutual Information from 0.69 to 1.04, confirming that scale normalization is essential for the pseudo-label path to meaningfully participate in the dual-path objective.

\paragraph{Bootstrap CI methodology.}
We report 95\% bootstrap CIs for the UCDPA--COME accuracy \emph{difference} $\Delta$. For each of 3 seeds, we compute per-corruption $\delta_{s,c} = \mathrm{acc}_\mathrm{UCDPA}(s,c) - \mathrm{acc}_\mathrm{COME}(s,c)$, pool the 57 values (3 seeds $\times$ 19 corruptions), resample 10{,}000 replicates of size 57 with replacement, and report the 2.5/97.5 percentiles of the mean-difference distribution. The paired permutation test randomly swaps UCDPA/COME labels within each (seed, corruption) pair 10{,}000 times; the reported $p$-value is the fraction of permutations with mean difference at least as large as observed.
